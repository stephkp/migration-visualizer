# FlowState — Global Migration Visualizer

An interactive visualization of global migration flows built with React and D3.

## Tech Stack

- **React 19** — UI framework
- **Vite** — Build tool & dev server
- **TypeScript** — Type safety
- **D3.js** — Data visualization (flow paths)
- **Framer Motion** — Animations

## Getting Started

```bash
yarn install
yarn run dev
```

## Project Structure

```
src/
├── components/    # React components
├── hooks/         # Custom React hooks
├── lib/           # Utilities
├── pages/         # Page components
└── types/         # TypeScript type definitions
```
